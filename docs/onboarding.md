# Onboarding

LISA simulates legitimate user activity on VMs for a cyber range.

- `backend/`  — FastAPI + PostgreSQL management API
- `agent/`    — POSIX activity agent (Linux + macOS)
- `frontend/` — React control panel
- `infra/`    — deployment

See `CONTRIBUTING.md` for the branch and PR workflow.
Quick start is in `infra/README.md`.

# Panel design reference

`panel-mockup.html` is a **visual design reference** for the LISA control panel —
it shows the intended look and feel (colour palette, typography, layout), not the
actual implementation.

The panel is built with **React + Vite** in `frontend/`. This mockup is a static
HTML/CSS prototype used only to guide that implementation — do not wire it into
the build.

## Design tokens (from the mockup)

- Palette: `#0D0F0C` (bg), `#122538` (deep), `#03365B` (mid), `#01669C` (accent),
  `#9BBACD` (light), `#F2F7FA` (white)
- Type: JetBrains Mono; pixel accent font "Nine By Five NBP"
